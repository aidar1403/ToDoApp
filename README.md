#  ToDo List Pro

## 👤 Authors
Kalysbekov Aidar, Salamov Amir, Docturbaev Erjan

##  Description
A modern task management application with graphical user interface built using Python and Tkinter. The application helps users organize, track, and manage their daily tasks efficiently with priorities and deadlines.

##  Problem Statement
People often forget important tasks and lose track of deadlines due to lack of a proper task management system. Existing solutions are either too complex or lack essential features like priority setting and deadline tracking.

##  Solution Overview
ToDo List Pro provides a simple yet powerful interface where users can:
- Add tasks with descriptions
- Set priority levels (High/Medium/Low)
- Set deadlines (Today/Tomorrow/This week/Next week/Custom)
- Track expired tasks
- Filter tasks by status and priority
- Change color theme

##  Technologies Used
- **Python 3.14** - Core programming language
- **Tkinter** - GUI framework (built-in with Python)
- **JSON** - Data storage format
- **datetime** - Date and time handling

##  Features
-  Add new tasks
-  Mark tasks as complete/incomplete
-  Delete tasks
-  Priority levels (High/Medium/Low)
-  Deadline setting and tracking
-  Expired task highlighting
-  Filter tasks (All/Active/Completed/Expired/By Priority)
-  Auto-save to JSON file
-  Custom color theme
-  Creation date tracking
